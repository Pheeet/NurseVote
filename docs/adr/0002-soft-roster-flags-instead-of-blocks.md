# Roster เตือน ไม่บล็อก

Squatting กันไม่ได้ 100% เพราะ Student Code ไม่ใช่ความลับ — มันอยู่บนรายชื่อและเอกสารทั่วไป
ทางเดียวที่จะบล็อกได้จริงคือต้องมีความลับที่มีแต่เจ้าตัวรู้ ซึ่งแปลว่าต้องแจกรหัสรายคนผ่านช่องทางที่เชื่อถือได้
เป็นภาระที่ไม่คุ้มกับงานนี้ เราจึงเลือกเป้าหมายที่ทำได้จริงแทน: **ตรวจจับได้ ย้อนกลับได้ สาวถึงตัวได้**

Roster (รายชื่อทั้งรุ่นที่ Admin นำเข้า) จึงทำหน้าที่เป็นข้อมูลอ้างอิง ไม่ใช่ประตู — รหัสที่ไม่อยู่ใน Roster
ยังลงทะเบียนได้ตามปกติ แต่ถูกทำเครื่องหมายเป็น Off-roster Registration ให้ Admin ไล่ตรวจ

## Considered Options

- **Strict roster (บล็อกรหัสนอกรายชื่อ)** — ปิด Squatting ที่มาจากรหัสปลอมได้สนิท แต่ถ้ารายชื่อตกหล่นแม้แต่คนเดียว
  คนนั้นจะลงทะเบียนไม่ได้เลยจนกว่า Admin จะว่าง ในงานที่มี deadline นี่คือความเสี่ยงที่รับไม่ได้
  และตอนตัดสินใจเรายังไม่รู้ด้วยซ้ำว่าจะได้รายชื่อครบหรือไม่

## Consequences

- ระบบต้องทำงานได้ปกติเมื่อ Roster ว่างเปล่า — ถ้าไม่ได้รายชื่อมาเลย ระบบก็ไม่แย่ลงกว่าเดิม
  ถือเป็นข้อกำหนด ไม่ใช่ผลพลอยได้
- สลับเป็น strict ภายหลังได้ด้วย flag ตัวเดียว เมื่อมั่นใจว่ารายชื่อครบ โครงสร้างไม่ต้องเปลี่ยน
- ต้องมีเครื่องมือฝั่ง Admin คู่กันเสมอ ไม่งั้น flag ที่ไม่มีใครดูก็ไร้ประโยชน์: รายการ Off-roster Registration,
  การดู Identity ที่ผูกกับแต่ละ Participant และปุ่มปลด Ownership เพื่อคืนสิทธิ์ให้เจ้าของตัวจริง
- ถ้าพบ Squatting หลังสั่ง Run ไปแล้ว ต้อง Run ใหม่ทั้งชุด เพราะ Choice ที่ใช้จัดสรรเป็นของคนสวมรอย
  ไม่ใช่ของเจ้าของตัวจริง
